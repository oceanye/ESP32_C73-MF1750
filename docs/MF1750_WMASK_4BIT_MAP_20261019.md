## 规律

1. **主导效应**：record 4 → 灰粉族（L47–49，a≈13，b≈-17）；record 5 → 深蓝族（L≈19，b≈-32）。6/7 单独只给藏青族弱调制（00/04/08 同族）。
2. **组合交互**：
   - {4,5} → 紫红/紫罗兰族（L25–27，a≈18–19.5），加 6 或 7（07/0B）不变。
   - {6,7} → 浅紫灰（L46.65，低彩度），与 {6}、{7} 单独完全不同。
   - **{4,6,7} → 近中性浅冷灰（L58.42，a≈1）**：4 的粉被 6+7 中和且明度抬高，是最接近期望"灰色阶梯"的点。
   - **{5,6,7} → 近中性深冷灰（L33.96，a≈3.3）**。
3. **近中性灰阶已现 5 级**：02 深蓝 L18.9（偏蓝）→ 0E L34.0 → 0C L46.7 → 0D L58.4 → OTP 白 L70；若只取 |a|≤7 的近中性点：0E(34.0) / 0C(46.7) / 0D(58.4) / 白(70)，加 04(31.2,a7.1) 与 1F(57.6,a7.8) 可作补充。
4. **drf 与场色脱钩**：所有变体 drf 同为慢 bin（PLL=0x02），场色差异纯由 records 内容决定。
