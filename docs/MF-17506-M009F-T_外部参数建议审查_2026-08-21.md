# MF-17506-M009F-T 外部参数建议审查

状态：`OFFLINE EVIDENCE REVIEW / NO DEVICE ACTION / NOT LIVE-AUTHORIZED`  
审查日期：`2026-08-21`  
适用范围：阶段二单像素颜色状态发现，以及后续可能的局刷、SPI 速率和波形研究

## 1. 结论

外部建议中，3.3 V 逻辑、电路现用的 SPI mode 0、MSB first，以及 BS0/BS1 拉低可纳入当前
精确实现；`BUSY active HIGH` 必须纠正为 **BUSY 忙时 LOW、空闲时 HIGH**。当前阶段只保留
已验证的 1 MHz SPI，不把 2–10 MHz 建议写入 D1-512 执行合同。

当前没有足以证明 MF-17506 + 双 SPD1657B 支持真局部刷新的精确命令资料，也没有可信的
runtime LUT 寄存器表。因此不猜测 `0x86`、`0x32` 或其他控制器命令，不把局部刷新写入当前
驱动。刷新中切断主电源会打断原厂波形和直流平衡；本项目当前明确不实现该路径。

- MF-17506 双控制器 1024×600 级联板的精确初始化和窗口合同；

本项目的精确板级实现、已封存 SPI 帧和实测 BUSY 极性优先于相邻型号样例和平台级宣传。

| SPI mode 0 | 接受 | 当前精确驱动使用 mode 0。 |
| SPI bit order = MSB first | 接受 | 当前精确驱动使用 MSB first。 |
| BS1 = LOW、BS0 = LOW | 接受 | 当前板通过 R12/R13 固定为低，按现有四线 SPI 接口使用。 |
| BUSY active HIGH | **纠正** | 实测与当前驱动合同均为忙时 LOW、空闲时 HIGH；不得反转等待条件。 |
| 1 MHz 起步 | 接受 | D1-512 固定 1 MHz；不得在同一发现批次改变 SPI 速率。 |
| 2–4 MHz normal、8–10 MHz upper | 推迟 | 尚未在本精确硬件合同下资格化；如需要，另立 N7 速率完整性测试，不与颜色发现混跑。 |

## 4. D1-512 当前安全实现边界

D1-512 仅复用已经验证的 factory OTP 完整刷新路径：

1. standard white baseline；
2. 512-recipe source frame；
3. 512-recipe mid frame；
4. 512-recipe target frame；
5. standard white recovery。

实际网格为每半屏 `11列 × 24行`，两半合计 `22×24=528` 个 ROI。每格 `40×22 px`，横向
白缝 4 px、纵向白缝 2 px，每半屏起点 `x0=16`，全屏 `y0=13`。512 格承载所有
`source0..7 × mid0..7 × target0..7` 候选；每个控制器另有 code 0–7 共 8 个参考格，左右合计
16 个参考格。所有候选格内部像素同态，不使用抖动或观看距离混色。

这五个动作仍是全屏 DTM 上传和全局 `PON→DRF→POF`，不是局部刷新。任何离线代码完成、测试
通过或固件构建都不构成上机授权；现场仍须在操作者返回后重新经过 J2-OFF、应用固件刷写和
只读身份检查边界。
