# 阶段二设计输入：ESP32-S3 与电池整合 Rev B

状态：设计简报；H1 第一轮器件/架构评估已记录，尚未冻结器件或布局。

前置条件：Rev A1 全屏级联已经通过；进入器件冻结前仍需补齐高压轨、峰值电流
和定量温升。

2026-08-05 的 ESP32 集成层级、TF 卡、共用 3.3 V 和 L1/L2 小型化结论见
[`H1_REV_B_MINI_COMPONENT_ASSESSMENT_2026-08-05.md`](H1_REV_B_MINI_COMPONENT_ASSESSMENT_2026-08-05.md)。

## 1. 目标

在 MF-1750 Rev A1 已验证的屏接口和高压驱动基础上，设计一块可由嘉立创
直接生产/贴片的一体板，包含：

- ESP32-S3 主控；
- USB-C 供电、原生 USB 烧录/调试；
- 单节 3.7V 锂电池充电和边充边用电源路径；
- 电池到稳定 3.3V 的稳压；
- 电源开关、BOOT/RESET、必要的 ESD/保护；
- 电池电压及充电状态检测；
- microSD/TF 卡槽及本地图片缓存；
- 软件可控的电子纸 3.3 V 负载开关；
- MF-1750 50Pin、高压驱动和测试点。

阶段二不应在没有首板证据时重新改变 Rev A1 的屏引脚、高压拓扑、R15/R16
策略或关键功率器件。

## 2. 建议基线架构

```text
USB-C VBUS ── ESD/输入保护 ── 带 power-path 的单节锂电充电器 ── BAT
     │                                  │                        │
     └── D+/D- ── ESP32-S3 原生 USB      └── SYS ── 3.3V buck-boost ──┬─ ESP32
                                                                    ├─ TF卡
                                                                    └─ 限流load switch ── EPD驱动

单节锂电池 ── 保护/温度检测 ──────────────────────────────────────────┘
```

不建议把无电源路径管理的 TP4056 直接作为最终“边充边用”方案。单节锂电
从约 4.2V 放电到约 3.0V，不能依靠普通 3.3V LDO 覆盖全电量范围。第一版
原理图和布局建议为 2A～3A 级 3.3V buck-boost 预留封装、铜宽和储能空间，
该范围是设计裕量而不是已测负载；最终额定值由 ESP32 Wi-Fi、TF 写卡和
Rev A1 刷新的叠加实测确定。

USB-C 应至少包括 CC1/CC2 下拉、VBUS/USB ESD、保险丝或限流、原生 USB
GPIO19/20 走线、BOOT/EN 和可恢复烧录通路。

## 3. ESP32 集成层级是首要决策

用户提出“只加芯片，还是把带 USB 的 ESP32 小板用邮票孔焊接”。应区分：

| 方案 | 优点 | 约束 | 当前定位 |
|---|---|---|---|
| 裸 ESP32-S3 SoC | 理论面积最小、GPIO 最自由 | 先冻结具体 SoC 变体，并为未封装内集成的 Flash/PSRAM 设计外部器件；仍需晶振、RF/天线和 EMC | 不推荐首版 |
| `ESP32-S3-PICO-1-N8R8` SiP | 约 7x7mm，集成 8MB Flash/8MB OPI PSRAM/晶振 | 仍需 RF 匹配、天线、阻抗控制和 EMC/RF 验证；LGA 返修难 | 激进小型化候选 |
| `ESP32-S3-WROOM-1-N8R8` 射频模组 | 延续实机 8MB Flash/8MB OPI PSRAM，GPIO 足、RF 风险低 | 主板自带 USB-C、稳压和按键；天线要净空 | **首选架构候选** |
| `ESP32-S3-MINI-1-N4R2` | 模组更小 | 仅 2MB PSRAM，必须重新验证内存峰值；N8 版本无 PSRAM | 后置小型化候选 |
| XIAO ESP32-S3 Plus 完整 USB 小板 | 21x17.8mm、引出 GPIO 较多、原型快 | 官方规格表与 pin map 的 GPIO 计数口径不同；重复 PCB/USB/稳压器，电源路径和机械受子板限制 | 工程样对照 |
| ESP32-P4 + ESP32-C6/网络模块 | JPEG/PPA 和大内存更适合高强度本地图像处理 | 双芯片、面积/供电/固件复杂；低频相框收益低 | 当前不采用 |
| 当前 DevKitC-1 | 已完整实测 | 体积大、排针结构，不是产品邮票孔板 | 仅台架 |

当前实物已经由 esptool 确认是 N8R8，PlatformIO 配置为 OPI PSRAM；完整帧为
307,200 字节，Web 接口要求从 PSRAM 分配完整帧。若希望保留现有 Wi-Fi 上传、
网页图像处理并增加 TF 缓存，优先保持 N8R8。只有完成 HTTP 分块、逐行量化/
推屏及全负载内存验证后，才重新评估 2MB PSRAM 的 MINI。

邮票孔并不等于“完整开发板”：WROOM 本身就是可 SMT 的认证射频模组，但不含
USB-C 和产品电源；XIAO Plus 才是带 USB、稳压和充电功能的完整子板。
PICO-1-N8R8 则是更小的 SiP，不是带天线的射频模组；只有 WROOM 包络不能满足
机械目标且项目接受 4 层/RF 验证时，才优先于 WROOM。

用户场景是低频刷新的相框。当前不因“本地量化”升级 P4：浏览器已经能在客户端
量化，主机色彩管线也可以封装成服务器 API；S3 N8R8 负责网络、TF 缓存、帧校验
和刷新即可。若后续必须完全离线处理大图，先在 S3 上实现流式/分块基础量化并
实测延迟、峰值内存和单次能耗，只有不达标才重开 P4 + 网络协处理器评审。

## 4. 建议保留的接口基线

- BUSY GPIO4、RST GPIO5、DC GPIO6。
- CS1 GPIO7、CS2 GPIO10；这是 R15 已拆、R16=0 Ω 后通过实屏验收的当前
  基线。R15 共片选只属于 Rev A1 早期历史，不进入 Rev B 默认设计。
- MOSI GPIO11、SCK GPIO12。
- USB D-/D+ 预留 GPIO19/GPIO20，并按官方要求布线。
- 增加一个屏/高压电源控制 GPIO，对应固件 `EPD_PIN_SWC`。
- TF 首版优先使用独立 SPI host，预留 TF_SCK、TF_MOSI、TF_MISO、TF_CS，
  可选 TF_CD；精确 GPIO 尚未冻结。
- 增加电池 ADC、充电状态输入，避免使用启动绑带冲突引脚。

GPIO 最终冻结前必须对照所选 ESP32-S3 模块数据手册、启动绑带、Flash/PSRAM
连接和 USB/JTAG 占用重新审计。

不建议第一版直接让 TF 与电子纸共享 SCK/MOSI。当前电子纸的 REV 等寄存器
诊断读取路径会把 MOSI 切为输入；正常整帧刷新不必然执行该动作，但共享仍会
扩展已验收 D0 的 GPIO 方向合同。断电安全状态还会把 EPD 片选拉低，而 SD SPI
初始化要求其他设备片选保持高。共享方案必须先解决 EPD 物理断电、片选状态、
总线互斥和初始化顺序，不能视为仅增加一个 MISO 和一个 CS。

TF 卡槽按 3.3V 设计，板边布置，加入外部上拉、就近去耦/储能和 ESD；读写
期间不得拔卡，固件需定义写入中断后的文件系统恢复策略。

## 5. 等待 Rev A1 提供的设计输入

至少记录：

1. 3.3V 静态电流；
2. 初始化、PON、DTM、DRF、POF 各阶段平均电流与峰值；
3. Wi-Fi 发送与刷新叠加时的最坏峰值；
4. TF 初始化、连续读取和最坏写入时的平均/峰值电流；
5. Wi-Fi、TF 写卡和刷新三者叠加的 3.3V 瞬态；
6. VPH、PREVGH、PREVGL、VPC 实测值与建立/衰减时间；
7. Q1/Q2/L1/L2/D1–D4 的最高温升；
8. 一次刷新耗时和估算能量；
9. 深睡眠目标及整板待机电流预算。

这些数据用于冻结充电电流、buck-boost 额定值、输入/输出电容、电池容量、
铜宽、散热和电源路径裕量。

## 6. 需要用户确认的产品选择

- 电池：单节软包锂电是否确定，容量和最大尺寸；是否自带保护板。
- 电池连接：JST-PH 2.0、焊线或其他接口；是否需要温度 NTC。
- USB-C：是否必须同时承担充电、供电和固件烧录（建议是）。
- 工作方式：是否要求插 USB 时边充边刷新。
- 机械：目标板尺寸、安装孔、外壳、USB 口和电源开关位置。
- 无线：板载天线还是外置天线版本。
- 主控：是否接受推荐的 WROOM-1-N8R8；是否另做 XIAO Plus 工程样。
- 极限尺寸：若 WROOM 过大，是否接受 PICO-1-N8R8 的 4 层、阻抗控制和
  RF/EMC 验证成本。
- 量化：服务器 API 为主、S3 本地后备的分层是否接受；P4 当前默认排除。
- 存储：TF 开口方向、card-detect、目标容量、FAT/exFAT 策略。
- 操作：需要哪些按键、状态 LED、蜂鸣器或低电量提示。

## 7. 布局约束

- ESP32 天线端必须放在板边，并执行模块厂商 keepout；天线下方及前方禁止
  铜、走线、器件和电池遮挡。
- USB D+/D- 成对、短、等长，远离 SW_H/SW_C、L1/L2 和高压泵节点。
- 充电器、buck-boost 与电子纸开关电源分区；大电流环路最小化并提供连续
  地回流，避免共享窄颈。
- TF 信号远离 SW_H/SW_C 和高压泵；卡槽的外露金属和触点设置 ESD 回路。
- USB 口、电池接口、开关、TF 卡口、FPC 方向先由机械约束冻结，再开始精细布线。
- 保留 Rev A1 的高压测试点，并增加 VBUS、BAT、SYS、3V3、充电状态和
  EPD_3V3/电池电流测量位置。

## 8. Rev B 验收标准

- ERC/DRC/原理图 parity 0；Gerber/BOM/CPL 位号一致。
- USB-C 供电、原生 USB 烧录、无电池启动均正常。
- 电池供电、充电、边充边用和欠压行为明确且无反灌。
- TF 检卡、读写、异常拔卡和掉电恢复符合冻结策略。
- 最坏刷新/Wi-Fi/TF 组合下 3.3V 不掉压复位，功率器件温升在设计限制内。
- EPD load switch 默认关闭、无反灌，固件可执行安全上电/POF/断电序列。
- 完整 1024×600 刷新、BUSY、POF 高压衰减正常。
- 深睡眠和关屏待机电流达到冻结目标。
- 嘉立创预览逐个核对有极性器件、模块 pin1、USB-C 和电池接口方向。

## 9. 下一阶段第一轮工作顺序

1. 阅读阶段一 handoff，并把 Rev A1 生产文件保持冻结。
2. 用户确认第 6 节产品选择。
3. 使用已经通过全屏级联的 Rev A1 补齐电流/温升/高压数据表。
4. 优先按 WROOM-1-N8R8 + 独立 TF SPI + EPD load switch 做电源/GPIO预算；
   如需快速原型，再并列评估 XIAO Plus。
5. 基于实测选择充电器、buck-boost、load switch 和保护器件。
6. 完成 Rev B 原理图评审，再进行 PCB 布局；不要跳过电源预算、TF 信号完整性
   和天线审计。
