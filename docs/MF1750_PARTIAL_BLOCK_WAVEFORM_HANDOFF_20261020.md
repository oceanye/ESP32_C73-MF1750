# MF-1750 多区域分块与跨波形局部保持交接

日期：2026-10-20；基线：main@38f702f。

目标是在不使用抖动的前提下，用同一块真屏同时观察多个区域，并验证不同 GrayExt 波形能否通过局部窗口共存。本文件只定义离线实现和真屏门，不授权自动刷屏。

## 当前事实

- wf_wmask_1E、wf_wmask_1C、wf_wmask_1D 当前使用完整帧 packed-4bpp 路径；完整帧可以包含多个 pixel code 区域，但一次 DRF 使用同一套 R20 waveform。
- 因此同一波形下可以一次刷新多个区域；0E、1E、1C 三套 R20 不能在同一次 DRF 中按区域独立选择。
- 仓库已有隔离的 PTLW partial-HOLD 研究路径，使用 0x83、9-byte 包含式窗口和 cropped DTM；这些旧证据尚未证明 GrayExt R20 在 SPD1657B 上可以跨波形局部保持。
- 0x83 窗口寻址不等于窗口外零电场。窗口外保持必须通过同机位相机验证；出现灰化、串色、黑边或旧区域漂移即停止。

## 两条路线

### 路线 A：同一波形的多区域 atlas

固定一个 profile，首选 1E，生成一张白底全屏帧，放置 4–8 个大 ROI，每区使用不同 code。一次完整刷新后同时测量所有区域。用于验证 packed-4bpp 多区域、同一 R20 下 code0–7 的色差和明度差，以及拍摄几何。它不证明不同 waveform 共存。

### 路线 B：不同波形的局部窗口共存

白底 → 1E 刷新窗口 A → 0E 刷新窗口 B 并保持 A → 1C 刷新窗口 C 并保持 A/B → 白恢复。每个不同 waveform 至少需要一次局部 DRF；多个区域可以在一次实验流程中完成，但不是一次 DRF 完成。

## 首批离线实现

新增与 wf_wmask_* 分离的 partial 研究环境，不修改生产环境和 GrayExt 完整帧环境。第一版固定：SPI 1 MHz；PTLW 0x83；9-byte 包含式窗口；窗口 160×120；cropped DTM；CS1/CS2 分别写窗口和 DTM；R20、PWR、PLL、R21、PSR/runtime 与对应完整帧 profile 字节一致。

不接受运行时坐标、未知命令、VCOM 或高压修改、任意 LUT 字节输入。窗口避开两个 512-pixel controller 接缝并满足偶数和字节边界。首批几何沿用已研究的三个窗口：A=(48,64,160,120)，B=(304,240,160,120)，C=(48,416,160,120)。

坐标语义固定为 x,y,width,height，发往控制器时转换为包含式 xe=x+w-1、ye=y+h-1。每个 action 记录窗口、控制器、DTM 字节数、R20 SHA、firmware SHA 和 BUSY 时间线。

## 真屏顺序与门

1. P0：先执行路线 A。一次完整 1E 刷新显示多个 code 区域，记录完整帧 hash、区域布局 hash、t0、t30、30 秒漂移和四位置 ROI。
2. P1：从生产白场只执行窗口 A 的 1E 局部刷新，检查 A 内颜色、A 外白底、窗口边缘、底边、controller 接缝和 5 分钟稳定性。失败时不执行 B/C，不重试当前 action，先独立白恢复并封存证据。
3. P2：P1 通过后才执行 A=1E、B=0E、C=1C。每次检查新 ROI、旧 ROI、窗口外背景、边缘和接缝；任一旧 ROI 褪色、变灰、偏色或面积变化，立即停止。
4. P3：三块完成后采集 t0、t30、5 分钟，最后独立白恢复。只有三块都保持且白恢复清除全部区域，才记为 same-panel multi-region cross-waveform coexistence preliminary pass。

## 判定和停止

- 新区域须与邻近已知状态有可分辨的 ΔL 或 ΔE，且 t0→t30 无明显漂移。
- 颜色比较固定相机、曝光、几何和 ROI；跨批绝对 Lab 必须记录照明 ratio。DRF 只作时序健康指标，不当作明度旋钮。
- 身份、payload、window、DTM、BUSY 或照片证据不完整，判 HOLD_FOR_EVIDENCE。
- 电气异常、BUSY 超时、窗口外明显变化、黑边或无法白恢复，判 FAIL_STOP。
- 路线 A 通过而路线 B 未通过时，可以继续同一波形的多区域 code atlas，但不能宣称跨波形共存。
- P2 通过后才扩大到 4–8 区域，优先同一 controller 内的窗口，最后才测试接缝附近。

本 handoff 不改变生产固件、不改变既有 GrayExt manifest，也不产生真屏刷新授权。

## 修订 1（2026-10-20，用户现场决定）

- **取消 5 分钟稳定性等待**：P1 的"5 分钟稳定性"与 P3 的"5 分钟"观察点统一改为只做 t0/t30。
- **每批增加同机位白屏对照**：批次内 OTP 白场基线照片兼作逐区域参考；多区域分析以**同区域白场 ΔL/Δa/Δb** 为主要比较口径，绝对 Lab 仅作辅助。目的是消除反光、照明梯度等局部区域效应。实现上由 `tools/mf1750_multi_roi_lab.py` 增加白场参考模式支持。
- 其余门（边缘/接缝/旧区保持/白恢复/BUSY）不变。
