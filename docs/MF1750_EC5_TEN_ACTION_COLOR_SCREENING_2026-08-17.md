# MF1750 五对 / 十次真屏色彩筛选操作卡

日期：2026-08-17

## 当前结论

十次真屏可以安排在同一个晚上完成，但必须作为五个独立的“彩色画面 → 白屏恢复”对执行，
不能做成自动十连刷。离线发布、固件身份、C/T 配对和动作次序可以预先闭合；现场仍必须逐动作完成
J2-OFF 刷写/诊断、人工电气确认、独立授权和永久 claim。

当前用户已离开现场且明确 J2 已物理断开。本卡不授权刷写、复位、联网诊断、打开 J2 或刷新。

## 十次可见动作

| 次序 | 分组 | 可见动作 | 主要用途 | 安全停点 |
|---:|---|---|---|---|
| 1 | WF20-C | C20 no-R20/R21 八码图卡 | WF20 同 header 对照 | 否 |
| 2 | WF20-C | C20 factory-OTP 白屏恢复 | 清屏并封存 C20 | 是 |
| 3 | WF20-T | T20 R20/R21 八码图卡 | 与 C20 同位置比较 | 否 |
| 4 | WF20-T | T20 factory-OTP 白屏恢复 | 清屏并封存 WF20 pair | 是 |
| 5 | WF23-C | C23 no-R20/R21 八码图卡 | WF23 同 header 对照 | 否 |
| 6 | WF23-C | C23 factory-OTP 白屏恢复 | 清屏并封存 C23 | 是 |
| 7 | WF23-T | T23 R20/R21 八码图卡 | 与 C23 同位置比较 | 否 |
| 8 | WF23-T | T23 factory-OTP 白屏恢复 | 清屏并封存 WF23 pair | 是 |
| 9 | OTP-Dither | Factory-OTP 矩形抖色色卡 | 筛查空间混色 | 否 |
| 10 | OTP-Dither | Factory-OTP 白屏恢复 | 最终干净白屏 | 是 |

其中恰好是 5 次彩色画面和 5 次白屏恢复。C20/T20 与 C23/T23 必须分别作差；禁止把
T20/T23 的直接差异解释成单纯 R20/R21 body 效果。抖色只能记作空间/知觉混色候选，不能记作
新的单像素电泳原色。

## 当晚入口

回到设备旁后，先保持 J2 OFF，不直接开始第一次刷新：

1. 在同一条消息重报完整 fresh 现场门：J2、USB、干净全白、3.3 V CV、精确温度、1.0 A
   限流、当前电流、监测与物理切断状态，以及离开期间是否发生 reset/flash/refresh/rewire。
2. 重新确认唯一候选地址；旧 gate、旧 token 和已过期 Phase-B authority 一律不复用。
3. 先完成当前 V10 的 J2-OFF Phase-B 三项只读诊断并取得 committed PASS。该步骤仍是
   `manifest → status → report`，不是可见刷新授权。
4. 只有上述步骤完成，才进入十次动作中的第 1 次。

## 每一次动作的固定边界

每次都重新执行以下步骤，不继承上一动作的 boot 或授权：

1. J2 OFF；只刷该动作冻结的 application image，并校验写后哈希。不得擦除 NVS、bootloader
   或分区表。
2. 同一新 boot 做正式 J2-OFF 四 GET 诊断；0 POST、0 claim、0 visible refresh。
3. 人工确认屏幕前态、电流、温度、限流和物理切断就绪。
4. 根据该次 diagnostic 派生新的逐字授权；授权在永久 claim 创建之前不得执行。
5. J2 ON 后只执行一个固定 action；禁止 retry、fallback、recovery 或 autochain。
6. 固定视角记录画面、温度、电流和异常；再将 J2 断开。
7. 深验并封存本次 result。未 finalization，不得准备下一次。

动作 2/4/6/8/10 还必须人工确认全屏干净白、无残留，并作为各组安全停点。任何时候都可以在
这些停点结束当晚测试，不需要为了“凑满 10 次”继续。

## 立即停止条件

以下任一项出现即停止，不补刷、不换固件尝试恢复：

- 身份、boot、manifest/status/report、claim 或 action ordinal 不匹配；
- 电流、3.3 V CV、温度、BUSY/driver evidence 或复位状态异常；
- 白屏恢复不干净；
- result 为 UNKNOWN、不能耐久落盘或不能深验；
- 人员无法持续监测或不能立即物理切断。

## “候选新色”与“确认新色”

十次筛选只能给出候选，不能单独得出“已确认新色”。候选至少满足：

- T20-C20 或 T23-C23 的同一图卡位置出现色相/颜色类别变化；
- 不是只有明暗、饱和度或抖色纹理差异；
- 左右控制器/多个对应 ROI 的观察不互相矛盾；
- 过程无电气或温度异常；
- 随后的 factory-OTP 白屏恢复干净。

固定曝光、固定白平衡、固定光源和固定机位照片应在每个彩色动作后、白屏恢复前取得。肉眼结果
只用于筛选；没有重复性和色度测量时，记录为 `CANDIDATE_NEW_HUE_REQUIRES_CONFIRMATION`。

## 候选出现后的后续路径

若出现候选新色，不自动进入全部 137+ 次资格动作。另开 fresh gate，仅对胜出路径依次做：

1. 重复性复验；
2. 固定采集和色度测量；
3. 仍为正结果时，再做根因控制、残影/白屏恢复、温度与 SPI 鲁棒性；
4. 最后才决定是否启动完整 N3--N8 资格计划。

若没有候选新色，十次动作完成后保持 J2 OFF 和干净白屏，停止该分支，不机械执行后续 137+
次刷新。

## 排程口径

“今晚可以集中测试”表示同晚按五个独立窗口顺序完成，不表示已经到现场执行门。建议为中途诊断、
拍照和人工观察保留充足时间；不得以赶时间为理由跳过白屏恢复、finalization 或 fresh gate。
