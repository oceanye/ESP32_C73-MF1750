## 1. 科学问题

在"历史配方 × 目标码"空间里，每个色相族（红/黄/绿/蓝/紫）存在多少**可分辨、可复现的
中间态**？判据（冻结门 `MF1750_LIGHTNESS_TEST_V1_20260911` 的 MAP-v2 适用形式）：
一个 (历史,目标) 单元的光学终点与**两端点**（历史端点色、目标端点色）均 ΔE00≥3，且该单元
在双侧/重复间自洽（ΔE00≤3、Δh≤5°），即记为一个新的独立中间态；产出按色相族分组的清单。

本批空间 = **active 电压域的"从彩色态出发"全映射**——正是 LH2 设计文档明确留白的
空间（"active 从彩色态图谱留作后续独立链"）。LH2 已测 commented 域：红族 2 级中间态、
蓝靛/棕/青各 1；暗光"中性 4 级"已被对账推翻（色度饥饿假象，本批 ≥0.85 照明门杜绝）。

## 3. 配方矩阵设计与推理

**拓扑**：每侧 8×8 主矩阵，行 r=历史码(0..7)，列 c=目标码(0..7)——每侧恰好覆盖全部
64 个 (历史,目标) 有向对一次（LUT 转换有向，A→B≠B→A，有向对必须全测）。双侧 = 128 个
独立测量单元（双侧一致性门自带）。

**为什么是 64 全映射而不是 LH2 的 16 配方**：LH2 的 16 配方是 commented 域端点重建
（机制问题）;MAP-v2 的科学问题是**转换终点着色**，所需输入就是全部有向对——L535 帧
路径两帧即天然给出（历史帧行=码、探针帧列=码），无需配方编码，矩阵即全集。

**哪些转换最可能产中间色**（基于既有数据的推理，优先级排序）：
1. **异色有向对**（彩↔彩）：红↔黄（橙/棕族）、蓝↔绿（青族）、红↔蓝（紫族）——LH2 的
   棕（M4, 32°）、青（M6, 240°）正是异色域端点；中间态大概率藏在有向转换的"半途"。
2. **彩↔白对**：commented 域已证"从白出发"是唯一的等级发生机制；active 域"彩→白"与
   "白→彩"是本批新空间（LH2 留白）。
3. **彩↔黑对**：LH2 发现 active code3 是历史无关暗吸引子（L*14.7, 309°）——若该吸引子
   在 active 域对一切历史成立，则 黑列/黑行 全部塌缩（这本身是要复核的机制断言）。
4. 码 2/5 行/列：L535 实测调色板无端点（未标定）——保留在矩阵内作**完整覆盖**，产出
   标注"未映射码"，不进入正式中间态清单（除非信号异常强）。

**不在本批的两个候选轴（论证）**：
- **异色历史对**（一格格内两码混合历史）：单帧单码/格是本批设计约束；混合历史的最小
  形式=两帧构建（H1 帧→H2 帧→探针帧）=4 刷，超本批预算，且"双码历史"的物理语义
  与 LH2 的单码历史不同类（像素级混合 vs 单元级），先建立单码基线再加密（§9 后续）。
- **部分驱动截断**：L535 帧路径的 /api/frame 只做完整 cascade init→LUT→DTM→全刷，
  无中途截断能力；截断需要 LH campaign 链的 PTLW 部分窗口架构（本批不引入）。
- **电压域微调**：表头旋钮生成器已就绪（vsh_lv 6000/6600/7200 三值真屏证明安全），
  但旋钮表需要 v3 变体固件（builder 生成的 .inc 编译进新 TU）——属离线可构建的
  后续步骤，本批先用钉死 active 表建立基线。

**规模 vs 预算**：主矩阵 64 对/侧 + 标定条 8 + 参照条 4 = 76 单元/侧，一帧探针全收；
总刷新预算 = **3**（OTP 白清 1 + 历史帧 1 + 探针帧 1）——无白清则历史被上一帧鬼影
污染（L535 自清弱已实证），不可省。

## 4. 治理选择：L535 帧路径变体（弃用 LH campaign 链）

选择变体路径（固件 `cb25e57c`,tag `MF1750_L535_FRAME_V1_20260926`），理由：
1. **历史构建的本质需求 = 同 LUT 下两次背靠背全帧驱动**。LH 链 MIDDLE→MAP 的物理
   过程与此完全同构；变体两个 /api/frame 即等价实现，且每刷都过完整
   job/diagnostic 治理面（fnv1a、DTM 双哈希、BUSY 时序、safe finish）。
2. **无砖风险面**：变体无 campaign 架构、无 NVS 绑定、复位安全、回退=重刷生产
   ba59c3d6（8 批实证流程）。LH campaign 链的砖风险铁律（NVS/cursor/claim/900s 窗/
   boot-binding）在本实验全部用不上。
3. **能力边界（明示）**：变体不能做部分窗口（PTLW）、不能中途截断、不能逐格选择
   profile——本批设计均不依赖这些；若未来要做截断/逐格 profile，必须回到 LH 链架构
   或新建多相驱动固件（§9）。
4. **朝向已知可控**：本批两帧均为 PAL1 类网格帧（该类 upright 3/3；demo 类 180° 6/6
   的机理仍与帧内容相关——探针帧含大比例白底码 7 背景，更接近 PAL1 类）；朝向判定
   内置（几何候选相关 + 亮蓝列位置 + 标定条三角对照），若判旋转则如实记录并列入
   下批预旋转补偿重发（本批预算内不重发）。

## 5. 帧设计（离线包 `CMAP_V2_20261009_R1`，audit PASS）

几何沿用 `lightness_history.py` 冻结放置表（X0=68,Y0=64,CELL 40×52,GAP=8，双矩阵）：
- **主矩阵**（每侧 64 格）：历史帧 格(r,c)=r；探针帧 格(r,c)=c。
- **标定条**（每侧 x=456 竖列 8 格）：历史帧全 7，探针帧 格=r → (白→码) 会话码轴
  + XOR-3 对照行（若 XOR-3 机制在本路径成立，此行应复现端点 c^3 的 Lab——不符即判
  该帧异常并全批降级为"机制异常证据"）。
- **参照条**（每侧底条 y=560 四块）：历史帧全 7，探针帧 [7,3,7,3] → 白参照（7→7，
  会话白锚）+ 暗参照（7→3，吸引子复核）。
- 背景全部码 7；两帧 sha 钉定（history `9136ec68…`,probe `7a2fb6fd…`）。

**与 LH2 帧的差异声明**：LH2 MAP 在 commented 域、单动作内完成；本批在 active 域、
两个独立 /api/frame 完成。中间态跨域可比性本身是一个产出（域效应），不比即新知。

## 6. 拍照时序、照明门与判决规则

- **照明**：≥0.85 硬门（对 LH1_REBOUND 参照 ROI 比值），无 force；日光类参照系
  （标定批同类的强日光；灯位/取景以 PAL1 批为基准）。
- **时序**（中间态=过渡态，衰减已实证）：探针刷新 job complete 后立即起拍——
  锚帧 ≤刷新完成+90s，随后 10 帧覆盖 ~300s（每 ~30s 一帧），产出每单元的衰减曲线；
  历史帧后、探针帧前拍 1 帧（历史态证据 + 鬼影检查）。
- **判决规则**（产出格式，每色相族一节）：
  | 字段 | 定义 |
  |---|---|
  | state_id | `CMAP-{family}-{n}`（按 L* 排序编号） |
  | cell | (历史码, 目标码)，双侧 Lab 中位 ± 噪声带 max(5×MAD, CI95) |
  | vs_endpoints | 与历史端点/目标端点（**会话内**标定条实测值）的 ΔE00/ΔL*/Δh |
  | reproducibility | 双侧一致（ΔE00≤3、Δh≤5°）+ 衰减曲线（300s 内 ΔE00 漂移） |
  | verdict | NEW_INTERMEDIATE / ENDPOINT_ALIAS（ΔE00<3 于某端点）/ ATTRACTOR_COLLAPSE / UNMAPPED_CODE(2/5) / MECHANISM_ANOMALY |
- 几何门 scatter≤15px（用户豁免已授）；标定条异常 → 全批降级，不产出中间态清单。

## 7. 现场 runbook（刷新预算 3，qualified 0/256，刷写铁律同前）

1. fresh 枚举（relay/IP/相机）→ relay ON → busy=1 → 锚帧照明门（≥0.85，日光类）。
2. **刷 #1**：生产固件 OTP 全白清底（frame_tool 完整验证，记录 drf_ms）→ 白场照。
3. relay OFF → J2-off 刷变体 `cb25e57c…` → relay ON → 版本预检 tag。
4. **刷 #2**：`history.frame4bpp`（kit 内 `cmap_v2_upload.py <batch> history`）→ 拍 1 锚帧
   （历史态证据）。
5. **刷 #3**：`probe.frame4bpp`（`... probe`）→ **立即** 1 锚帧 + 10 衰减帧（≤90s 起，
   ~30s 间隔）。
6. relay OFF → J2-off 回刷生产 `ba59c3d6…` → 版本确认 → 屏保留探针帧。
7. 离线分析：几何/朝向 → 标定条会话端点 → 逐单元 Lab+衰减 → §6 判决 → 清单产出。
8. 批次自封（manifest canonical sha）。
