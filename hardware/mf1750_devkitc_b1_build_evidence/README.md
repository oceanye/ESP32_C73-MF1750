# Rev B1 build evidence — not release inputs

This directory contains superseded intermediate DRC reports, the initial
netlist, KiCad local UI state, and pre-final previews from development of the
single-power-layer Rev B1 candidate.  Some reports intentionally record
violations that were subsequently fixed.

Do not use these files for fabrication or acceptance.  The authoritative
candidate and its hash-bound final reports are in
`hardware/mf1750_devkitc_b1_single_power_layer/` and are enumerated by that
directory's `verification_manifest.json`.
